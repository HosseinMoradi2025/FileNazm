## 📌 معرفی

فایل‌نظم پوشه‌های مشخصی را زیر نظر می‌گیرد و با تعریف قوانین، فایل‌های جدید یا منتقل‌شده را بر اساس پسوند، نام، تاریخ، حجم یا محتوا به پوشه‌های هدف منتقل، کپی یا به سطل بازیافت ارسال می‌کند.

---

## 🚀 قابلیت‌ها

- تعریف چندین قانون برای پوشه‌های مختلف
- نظارت خودکار بر پوشه‌ها (watchdog)
- فیلتر فایل‌ها بر اساس پسوند، glob نام، حجم و محتوا
- انتقال فایل به پوشه مقصد
- کپی فایل به پوشه مقصد
- حذف فایل با ارسال به سطل بازیافت (send2trash) یا حذف مستقیم
- پشتیبانی از متغیرها در مسیر مقصد
- ساخت خودکار پوشه بر اساس تاریخ، سال، ماه، نام یا پسوند فایل
- آیکون در System Tray (pystray)
- شروع خودکار با ویندوز (Registry HKCU Run)
- گزارش عملیات داخل برنامه
- ذخیره تنظیمات محلی در `%LOCALAPPDATA%\FileNazm`
- خواندن محتوا از PDF (pypdf) و DOCX (python-docx) به‌صورت اختیاری
- بدون نیاز به اینترنت
- بدون جمع‌آوری اطلاعات کاربر یا telemetry
- رابط کاربری فارسی (tkinter/ttk)

## 🧩 متغیرهای مسیر مقصد

| متغیر | توضیح |
|---|---|
| `{name}` | نام فایل بدون پسوند |
| `{ext}` | پسوند فایل |
| `{date}` | تاریخ فایل (YYYY-MM-DD) |
| `{year}` | سال میلادی فایل |
| `{month}` | ماه میلادی فایل |
| `{rule}` | نام قانون (slugify‌شده) |

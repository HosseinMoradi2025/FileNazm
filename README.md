# 🗂️ فایل‌نظم / FileNazm

✨ **فایل‌نظم** یک ابزار سبک ویندوزی برای مرتب‌سازی خودکار فایل‌ها است.

شما می‌توانید مشخص کنید که کدام پوشه زیر نظر گرفته شود. فایل‌نظم آن پوشه را رصد می‌کند و وقتی فایل جدیدی در آن ساخته یا منتقل شود، بر اساس قانونی که شما تعریف کرده‌اید، فایل را به‌صورت خودکار مرتب می‌کند.

فایل‌نظم می‌تواند فایل‌ها را منتقل کند، کپی کند یا به سطل بازیافت بفرستد. همچنین می‌توانید از اطلاعات فایل مانند نام، پسوند، تاریخ، سال و ماه برای ساخت پوشه‌های منظم استفاده کنید.

---

## 🚀 قابلیت‌ها

- 📁 انتقال فایل به پوشه مقصد
- 📋 کپی فایل به پوشه مقصد
- 🗑️ حذف فایل با ارسال به سطل بازیافت
- 🔍 فیلتر فایل‌ها بر اساس پسوند
- 🧩 پشتیبانی از نام، پسوند، تاریخ، سال و ماه فایل
- 🗂️ ساخت پوشه‌های منظم بر اساس تاریخ یا سال فایل
- 🖥️ آیکون کنار ساعت ویندوز
- ⚙️ شروع خودکار با ویندوز
- 📝 گزارش عملیات داخل برنامه
- 💾 ذخیره تنظیمات به‌صورت محلی
- 🔌 بدون نیاز به اینترنت
- 🛡️ بدون ارسال اطلاعات کاربر

---

## 🧩 متغیرهای مسیر مقصد

در مسیر مقصد می‌توانید از متغیرهای زیر استفاده کنید:

| متغیر | توضیح |
|---|---|
| `{name}` | نام فایل بدون پسوند |
| `{ext}` | پسوند فایل |
| `{date}` | تاریخ فایل |
| `{year}` | سال میلادی فایل |
| `{month}` | ماه میلادی فایل |
| `{rule}` | نام قانون |

مثال:

```text
D:\مرتب‌شده\{year}\{month}\{name}.{ext}
```

اگر فایلی با تاریخ سال ۲۰۲۶ و ماه ۱۰ داشته باشید، فایل‌نظم آن را در پوشه مناسب قرار می‌دهد.

## 🎯 فایل‌نظم برای چه کسانی مناسب است؟

فایل‌نظم برای کاربرانی مناسب است که می‌خواهند پوشه‌هایی مانند:

- 📥 دانلودها
- 📤 پوشه دریافتی
- 🖨️ اسکن‌ها
- 💼 فایل‌های کاری
- 🧾 فاکتورها و مدارک
- 📂 پوشه‌های پرمصرف و نامنظم

را به‌صورت خودکار و منظم نگه دارند.

## 📦 نصب

1. به بخش **Releases** پروژه بروید.
2. فایل `FileNazm_Setup.exe` را دانلود کنید.
3. آن را اجرا کنید.
4. اگر پیام ادمین/UAC آمد، گزینه **Yes** را بزنید.
5. مراحل نصب را کامل کنید.

 دانلود فایل نصب از بخش Releases:

[دانلود فایل نصب فایل‌نظم](https://github.com/HosseinMoradi2025/FileNazm/releases/tag/v1.0.0)

- 🔑 نصب برنامه به دلیل قرارگیری در پوشه `Program Files` به دسترسی ادمین نیاز دارد.

## 💾 محل تنظیمات

تنظیمات فایل‌نظم در پوشه کاربر ذخیره می‌شود:

```text
%LOCALAPPDATA%\FileNazm\rules.yaml
```

فایل لاگ نیز در این مسیر ذخیره می‌شود:

```text
%LOCALAPPDATA%\FileNazm\filenazm.log
```

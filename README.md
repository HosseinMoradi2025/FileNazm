## 📜 لایسنس اختصاصی فایل‌نظم

فایل‌نظم تحت **لایسنس اختصاصی فایل‌نظم** منتشر می‌شود. متن کامل لایسنس در فایل [LICENSE](https://github.com/HosseinMoradi2025/FileNazm/blob/main/LICENSE) موجود است.

این لایسنس شماره نسخه ندارد و برای انتشارهای فعلی و آتی، بدون نیاز به تغییر شماره نسخه نرم‌افزار، قابل استفاده است.

### موارد مجاز

- استفاده شخصی و آموزشی
- استفاده تجاری در شرکت، سازمان یا کسب‌وکار
- نصب روی هر تعداد دستگاه موردنیاز برای خود یا سازمان
- تغییر، توسعه، شخصی‌سازی و رفع ایراد
- انتشار نسخه اصلی یا تغییریافته، مشروط بر شرایط لایسنس
- ارائه خدمات مستقل مانند نصب، پیکربندی، آموزش، پشتیبانی، مشاوره یا یکپارچه‌سازی و دریافت دستمزد بابت آن خدمات

### موارد ممنوع

- فروش خود فایل‌نظم
- فروش هر نسخه تغییریافته یا اثر مشتق از فایل‌نظم، حتی با نام، ظاهر یا بسته‌بندی کاملاً متفاوت
- فروش یا اجاره دسترسی به نرم‌افزار به‌عنوان محصول یا خدمت مستقل
- بسته‌بندی مجدد نرم‌افزار یا نسخه مشتق‌شده با نام دیگر به‌منظور فروش
- ثبت نام «FileNazm» یا «فایل‌نظم» یا نام‌های مشابه به‌عنوان علامت تجاری یا برند
- معرفی نسخه تغییریافته به‌عنوان نسخه رسمی یا تأییدشده سازنده
- حذف یا تغییر اعلان‌های کپی‌رایت، نام سازنده یا متن لایسنس

### تفاوت استفاده تجاری و فروش

استفاده از فایل‌نظم در کسب‌وکار و دریافت هزینه بابت خدمات مستقل مجاز است؛ اما فروش خود نرم‌افزار یا نسخه مشتق‌شده‌ای که بخش‌های اختصاصی فایل‌نظم را شامل می‌شود، ممنوع است.

### مجوزهای اجزای شخص ثالث

نرم‌افزار ممکن است شامل یا وابسته به کتابخانه‌ها و اجزای شخص ثالث باشد. حقوق هر جزء تابع مجوز مستقل خودش است. فهرست واقعی اجزای شخص ثالث و مجوزهای آن‌ها باید در فایل `THIRD-PARTY-LICENSES.txt` یا مستندات پروژه به‌صورت بررسی‌شده ذکر شود.

# ✨ فایل‌نظم (FileNazm)

فایل‌نظم یک ابزار سبک و ویندوزی برای مرتب‌سازی خودکار فایل‌ها و سازمان‌دهی پوشه‌ها است. پوشه‌های مشخصی را زیر نظر بگیرید و با تعریف قوانین، فایل‌های جدید یا منتقل‌شده را به‌صورت خودکار مرتب کنید.

| مورد | مقدار |
|---|---|
| نسخه | 1.1.0 |
| وضعیت | انتشار عمومی |
| پلتفرم هدف | Windows 7 SP1 x64 و نسخه‌های جدیدتر |
| رابط کاربری | فارسی |
| لایسنس | FileNazm Custom License 1.0 |
| آخرین به‌روزرسانی این سند | ۲۸ اکتبر ۲۰۲۶ |

> این سند برای نسخه 1.1.0 به‌روزرسانی شده است. مقدار SHA256 نسخه 1.1.0 در زیر آمده و وضعیت بازبینی False-Positive نزد مایکروسافت پس از تکمیل فرآیند WDSI نهایی می‌شود.

## 🎬 تماشای ویدیوی معرفی فایل‌نظم در آپارات

در این ویدیو، نحوه ساخت قانون، شروع نظارت و مرتب‌شدن خودکار فایل‌ها به‌صورت عملی نشان داده شده است.

فایل‌نظم به شما کمک می‌کند پوشه دانلودها، اسکن‌ها، مدارک، فاکتورها و فایل‌های کاری را با تعریف قانون، نظارت بر پوشه‌ها، انتقال فایل، کپی فایل و حذف با ارسال به سطل بازیافت، به‌صورت خودکار سازمان‌دهی کنید.

به‌جای مرتب‌سازی دستی، یک بار قانون تعریف کنید تا فایل‌نظم از آن پس فایل‌ها را مدیریت کند.

## 🧩 معماری نسخه ۱.۱.۰

نسخه ۱.۱.۰ از معماری تک‌فایلی نسخه ۱.۰.۰ به یک معماری ماژولار و سبک مهاجرت کرده است:

- فایل `FileNazm.py` فقط نقطهٔ ورود (entry point) برنامه است و منطق اصلی در ماژول‌های جداگانه پیاده‌سازی شده است: `ui.py`، `engine.py`، `model.py`، `preview.py`، `animation.py`، `drawing.py`، `resources.py`، `flow.py`، `editor.py`، `config_yaml.py`، `document_text.py`، `native_tray.py`، `native_files.py` و `raster.py`.
- **زمان اجرا هیچ کتابخانه شخص‌ثالث پایتون ندارد.** تمام قابلیت‌ها (پارس YAML، استخراج متن PDF/DOCX، System Tray، نظارت بر پوشه، سطل بازیافت و پیش‌نمایش متحرک) با کتابخانه استاندارد پایتون و Win32 API پیاده‌سازی شده‌اند.
- فایل اجرایی نهایی با PyInstaller بسته‌بندی می‌شود؛ به همین دلیل برخی موتورهای امنیتی آن را به‌صورت False-Positive علامت می‌زنند (توضیح کامل در بخش VirusTotal).

## 🆕 تغییرات مهم نسخه ۱.۱.۰

- حذف PyYAML و جایگزینی با پارسر تنظیمات داخلی مبتنی بر کتابخانه استاندارد پایتون
- حذف Pillow و جایگزینی با موتور raster/GDI داخلی برای پیش‌نمایش متحرک
- حذف pystray و جایگزینی با System Tray داخلی مبتنی بر Shell_NotifyIconW
- حذف watchdog و جایگزینی با نظارت پوشه داخلی مبتنی بر ReadDirectoryChangesW
- حذف Send2Trash و جایگزینی با حذف به سطل بازیافت داخلی مبتنی بر SHFileOperationW
- حذف pypdf و python-docx و جایگزینی با استخراج متن داخلی PDF/DOCX
- بهبود ایمنی عملیات فایل، پشتیبان‌گیری، Undo/Redo و جابه‌جایی بین درایوها
- پشتیبانی بهتر از کیبورد فارسی برای Ctrl+Z و Ctrl+Y
- حفظ مسیر ارتقا از نسخه ۱.۰.۰ (نصب روی نسخه قبلی بدون تداخل)

## 📂 متغیرهای مسیر مقصد

| متغیر | توضیح |
|---|---|
| `{name}` | نام فایل بدون پسوند |
| `{ext}` | پسوند فایل |
| `{date}` | تاریخ فایل |
| `{year}` | سال میلادی فایل |
| `{month}` | ماه میلادی فایل |
| `{rule}` | نام قانون |

مثال:

```text
D:\Sorted\{year}\{month}\{name}.{ext}
```

در این مثال، فایل‌ها بر اساس سال و ماه در پوشه‌های منظم قرار می‌گیرند.

## ⬇️ نصب

۱. به بخش [Releases](../../releases) پروژه مراجعه کنید.
۲. فایل `FileNazm_1_1_0.exe` را دانلود کنید.
۳. در صورت نیاز، اثر انگشت فایل را با SHA256 بررسی کنید (بخش پایین).
۴. فایل نصب را اجرا کنید.
۵. اگر پیام UAC نمایش داده شد، در صورت اطمینان از منبع فایل، گزینه Yes را بزنید.
۶. مراحل نصب را کامل کنید.

نصب برنامه به دلیل قرارگیری در پوشه `Program Files` به دسترسی Administrator نیاز دارد.

## 🦠 گزارش VirusTotal نسخه 1.1.0

فایل نصب `FileNazm_1_1_0.exe` نسخه 1.1.0 در VirusTotal بررسی شد.

- **نتیجه:** ۴ از ۷۱ موتور تشخیص، فایل را علامت‌گذاری کردند.
- **موتورهای علامت‌گذاری‌کننده:** Arctic Wolf (Unsafe)، SecureAge (Malicious)، DeepInstinct (MALICIOUS)، Skyhigh/SWG (Behaves.Like.Win32.Dropper.vc).
- **SHA256:** `022394d48667bdfca7df2f6d97859cfd807e1209dbf24efd242fa2b561322352`
- **حجم فایل:** ۱۰٫۳۲ مگابایت
- **تاریخ بررسی:** ۲۸ اکتبر ۲۰۲۶
- **لینک گزارش:** [مشاهده در VirusTotal](https://www.virustotal.com/gui/file/022394d48667bdfca7df2f6d97859cfd807e1209dbf24efd242fa2b561322352)
- **وضعیت بازبینی False-Positive نزد Microsoft Defender / WDSI:** در حال ثبت

این فایل با PyInstaller ساخته شده و به‌صورت محلی روی ویندوز اجرا می‌شود. برچسب‌های `dropper` و `overlay` که برخی موتورهای امنیتی نمایش می‌دهند، ناشی از رفتار واقعی برنامه (جابه‌جایی/کپی/حذف فایل، نصب در Program Files، مدیریت فرآیند خود و نوشتن کلید autostart) و ذات بسته‌بندی یک‌فایل PyInstaller است، نه نشانه‌ی malware. استفاده از Win32 API و بسته‌بندی بدون امضا گاهی باعث False-Positive می‌شود. تشخیص موتورهای امنیتی ممکن است با گذشت زمان تغییر کند و به‌تنهایی اثبات ویروسی‌بودن یا بی‌خطر بودن فایل نیست. فایل اجرایی با گواهی رسمی Code Signing امضا نشده است؛ بنابراین ممکن است SmartScreen هشدار نشان دهد.

## ⚠️ محدودیت‌ها و هشدارها

- این برنامه می‌تواند فایل‌ها را جابه‌جا، کپی یا حذف کند؛ قوانین را ابتدا روی پوشه‌های غیرحساس آزمایش کنید.
- پیش از استفاده روی پوشه‌های مهم، از فایل‌های ارزشمند خود پشتیبان بگیرید.
- فایل‌های اجرایی با گواهی رسمی Code Signing امضا نشده‌اند؛ بنابراین ممکن است SmartScreen یا برخی آنتی‌ویروس‌ها هشدار نشان دهند.
- تنظیمات در پوشه کاربر ذخیره می‌شود و با حذف برنامه لزوماً پاک نمی‌شود.
- مسیر پوشه نظارت و پوشه مقصد را با دقت انتخاب کنید.
- در حالت نظارت بازگشتی (Recursive)، پوشه مقصد را داخل همان پوشه نظارت قرار ندهید؛ این کار ممکن است باعث حلقه شود.
- از قرار دادن symlink یا junction داخل پوشه نظارت خودداری کنید، مگر اینکه رفتار آن را کاملاً بررسی کرده باشید.
- استخراج متن PDF محدود به PDFهای بدون رمزنگاری و با فیلترهای پشتیبانی‌شده است؛ PDFهای پیچیده به‌صورت fail-closed رد می‌شوند.

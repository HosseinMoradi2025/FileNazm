# 🗂️ فایل‌نظم | FileNazm

✨ **فایل‌نظم** یک ابزار سبک و ویندوزی برای سازمان‌دهی خودکار فایل‌ها است.

شما می‌توانید پوشه‌های مشخصی را زیر نظر بگیرید و قواعدی تعریف کنید که بر اساس آن‌ها فایل‌های جدید یا منتقل‌شده به‌صورت خودکار مرتب شوند.

📁 انتقال فایل  
📋 کپی فایل  
🗑️ حذف فایل با ارسال به سطل بازیافت  
🧩 ساخت پوشه‌های منظم بر اساس نام، پسوند، تاریخ، سال و ماه فایل  

**نسخه:** 1.0.0  
**وضعیت:** انتشار عمومی  
**پلتفرم هدف:** Windows 7 SP1 x64 و نسخه‌های جدیدتر  
**رابط کاربری:** فارسی  

---

## 📌 معرفی

فایل‌نظم برای کاربرانی مناسب است که می‌خواهند پوشه‌های پرمصرف خود را به‌صورت خودکار و منظم نگه دارند.

از جمله کاربردهای آن:

- 📥 مرتب‌سازی پوشه دانلودها
- 🖨️ دسته‌بندی اسکن‌ها و مدارک
- 💼 سازمان‌دهی فایل‌های کاری
- 🗂️ بایگانی خودکار بر اساس سال و ماه
- 📤 مدیریت پوشه‌های دریافتی
- 🧹 پاک‌سازی پوشه‌های موقت

به‌جای مرتب‌سازی دستی، شما یک بار قانون تعریف می‌کنید و فایل‌نظم از آن پس به‌صورت خودکار فایل‌ها را مدیریت می‌کند.

## 🧩 متغیرهای مسیر مقصد

در مسیر مقصد می‌توانید از متغیرهای زیر استفاده کنید:

| متغیر | توضیح |
|---|---|
| `{name}` | نام فایل بدون پسوند |
| `{ext}` | پسوند فایل |
| `{date}` | تاریخ فایل |
| `{year}` | سال میلادی فایل |
| `{month}` | ماه میلادی فایل |
| `{rule}` | نام قانون |

مثال:

```text
D:\Sorted\{year}\{month}\{name}.{ext}
```

در این مثال، فایل‌ها بر اساس سال و ماه در پوشه‌های منظم قرار می‌گیرند.

## 📦 نصب

1. 🌐 به بخش Releases پروژه مراجعه کنید.
2. 📥 فایل `FileNazm_Setup.exe` را دانلود کنید.
3. ▶️ فایل نصب را اجرا کنید.
4. 🔑 اگر پیام ادمین یا UAC نمایش داده شد، گزینه Yes را بزنید.
5. 🏁 مراحل نصب را کامل کنید.

## 💻 نیازمندی‌ها

- 🪟 Windows 7 SP1 x64 یا نسخه‌های جدیدتر
- 🔑 دسترسی Administrator برای نصب برنامه

نصب برنامه به دلیل قرارگیری در پوشه `Program Files` به دسترسی ادمین نیاز دارد.

---

## 💾 محل ذخیره‌سازی تنظیمات

تنظیمات فایل‌نظم در پوشه کاربر ذخیره می‌شود:

```text
%LOCALAPPDATA%\FileNazm\rules.yaml
```

فایل لاگ برنامه نیز در این مسیر ذخیره می‌شود:

```text
%LOCALAPPDATA%\FileNazm\filenazm.log
```

## 🔒 حریم خصوصی

فایل‌نظم کاملاً محلی است؛ بدون نیاز به اینترنت، بدون جمع‌آوری اطلاعات کاربر و بدون ارسال داده.

- ❌ به اینترنت نیاز ندارد
- ❌ اطلاعات کاربر را ارسال نمی‌کند
- ❌ داده‌های کاربر را جمع‌آوری نمی‌کند
- ❌ داده‌های استفاده یا آماری نمی‌فرستد
- ✅ فقط فایل‌ها و تنظیمات محلی را مدیریت می‌کند
